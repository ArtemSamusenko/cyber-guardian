# Audio

Made with `tools/generate_audio.py` (needs numpy and ffmpeg). To use a different sound, replace the file with an MP3 of the same name.

| File | Used for |
|------|----------|
| `music/menu_ambient.mp3` | Main menu |
| `music/gameplay_cyberpunk.mp3` | Levels |
| `music/story_dramatic.mp3` | Story scenes |
| `sfx/click.mp3` | Button clicks |
| `sfx/hover.mp3` | Button hover |
| `sfx/success.mp3` | Correct answer |
| `sfx/failure.mp3` | Wrong answer |
| `sfx/level_complete.mp3` | Level complete |
| `sfx/achievement.mp3` | Achievement unlocked |
| `sfx/typing.mp3` | Typewriter text |
| `sfx/alert.mp3` | Alerts |
