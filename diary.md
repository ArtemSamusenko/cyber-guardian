# Week 2+3 - tech stack and core concepts

## Tech Stack
*frontend*: phaser, typescript, tailwind for styling
Phaser as its extremely popular and there are a lot of resources for it out here.
Typescript to ensure type safety, specifically when it will come to sending/receiving requests to/from backend
Tailwind also as its the most popular styling framework + ability to use already-made templates

*backend*: python fastapi, psql, pydantic for model validation
Python for the backend as I am more comfortable with python as opposed to js/ts. I also have used python for backend before specifically.
FastAPI as it comes with a lot of quality of life stuff built in and is easy to set up and get started as oppossed to needing to configure other python web frameworks.
Psql as database as its performant and I have experience with it before. I want to focus on getting a proof of concept ready first so I don't want to experiment with mongo/nosql variants.
Pydantic for schemas/models as again it will be easier to figure out errors regarding frontend and backend communication.
